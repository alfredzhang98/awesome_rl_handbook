# 交稿前自检

前 25 条是版式与体例；**第 26 条起是这本讲义真正翻过车的地方，一条都别跳。**

## 内容

1. 这一课有没有**一个能手算的小例子**？读者不用跑代码就能验证第一个数字吗？
2. 本课例子（CartPole/…）在这一课里落地了吗？有没有「落点」段落说明该跑什么实验、该看什么差别？
3. 正文里每一个数，是否都能在随附脚本里重跑出来？
4. 先给数字再给公式，还是反了？
5. 有没有至少一处「破误解」——指出读者大概率的错误理解并纠正？
6. 这一课的边界写了吗（什么时候这套东西不成立 / 失效点）？
7. 收尾节在不在？能不能只读收尾就复述整课？

## 结构

8. `parttag / kicker / h1(两行) / lede` 四件套齐了吗？
9. `h2` 都带 `<span class="n">§ N</span>` 吗？一课 6–10 节？
10. `<footer>` 两句话齐了吗（下一课去哪 + 数字来源与重跑耗时）？
11. `.key` 每节 ≤ 1 个，且首句是完整断言？
12. 新加的组件有没有写死颜色？（只准用 `var(--…)`）
12a. **每个 `<h2>` 下面都有 `.lead` 承接行吗**（习题、小结除外）？三段齐不齐：
     上一节交出了什么 / 还缺什么 / 这一节干什么？中间那段最容易掉。
12b. 承接行和正文首段有没有说同一句话？有就把首段那句删掉。
12c. 随手抽三节，能不能立刻答出「为什么这里会有这一节」？答不上来先想想是不是该并掉。

## 公式

13. `V^\star` 渲染成 ⋆，正文里没有残留黑星 ★？
14. `k`（迭代）与 `t`（时刻）没有混用；换符号处有公告？
15. 关键式子有 `\underbrace{…}_{…}` 标注？
16. 每个公式后面有一句白话复述？
17. 页面里所有 `xlink:href="#MJX-…"` 都能在 `<defs>` 里找到？

## 图

18. 每张数据图都有亮/暗两版，且尺寸布局一致？
19. `figcaption` 是「左：…右：…」式说明书，带具体数字，而不是标题？
20. `alt` 写了公式含义？

## 交付

21. 断网双击打开：公式显示正常、图能看见、交互能点？
22. 深色模式切一遍，有没有对比度炸掉的地方？
23. 窄屏（手机宽度）看一遍，表格和公式能横向滚动而不撑破页面？
24. 跨章链接、侧栏高亮、上一章/下一章都对？
25. `python publish.py` 跑通、Pages 页面刷新出来了？

## 逻辑链与符号（必查）

26. 开头能不能一句话说清**上一课在哪一步不再成立**？没有就补。
27. 结尾有没有写**这一课自己引入了什么新问题**？这是下一课存在的理由，不能省。
28. 正文里出现的**每一个变量**，是不是都在第一次出现时定义过？
29. 符号有没有和前面的课冲突（`V^π` / `V⋆` / `V_k`、`α`、`θ`、`λ`）？
30. 有没有「显然」「容易看出」「不难证明」？有就把那一步补出来。
31. **本页目录测试**：把这一课所有 h2 抽出来单列一行行读——像教材目录，还是像一串摘要？
    有没有「角色标签：」式前缀（冒号只留给「示例：」「实验：」）？有没有设问 / 动作 / 场景 / 评论式的名字？
32. 例子是不是小到能手算，而且**不需要控制或物理背景**？
33. 路线图那张卡片的五行账本（极限 / 做法 / 解决了什么 / 又引入什么 / 下一步）填全了吗？

## 引用与重复（必查）

34. 全文搜 `第 . 课 §` —— 应该 **0 命中**。跨章一律写「上一课 / 下一课」，或者干脆把那句话说完。
35. 有没有引用还没写出来的章节？路线图上排着不等于读者点得开。
36. 同一个记号有没有在两课里各自完整定义一遍？后来的那一课只该回忆一行。
37. 同一件事有没有在同一节里说两遍？（典型：一段正文说完，紧跟的 `.key` 又原样说一次。）
38. 同一张表、同一张图、同一个交互组件有没有印两份？确实需要对照时，只留新的那一份，旧的压成一行。
39. 同一个量有没有两套记号并存？插图内部的标注也要一起数。
40. 全文搜 ASCII 直引号 `"` —— 正文里应该 0 命中（`<style>` / `<script>` 里的不算）。
41. 有没有「顺带纠一个常见的说法」式的段落，反驳的却是讲义里从没写过的话？有就改成正面陈述。
42. 有没有在评论已经删掉的旧内容？读者看不到那一版。
43. **跑一遍跨小节重复扫描**：正文去标签去空白，取 9 字滑窗，
    找出现在两个以上小节里的片段。命中之后逐条判：
    - 允许：本章小结回顾、约定句式（「这个式子读一遍就够了」）、图注格式、组件里重复的控件文案
    - 不允许：同一条论证讲两遍、同一个数的来历算两遍、展望块把下一节的正文提前讲完
    处理办法一律是：**信息最全的那处留全文，其余改成回指**，回指时带上新增的部分。
44. 习题、小结里有没有混进正文的结论句（整句照搬）？习题只出题，不给结论。

## 数字口径（必查）

43. 同一个词（「一次备份」「一遍」「一轮」）在两课里是不是同一个口径？不同就当场挑明并给换算。
44. 同一张表里的几行，是不是用同一套跑法算出来的？（混口径最难发现，也最丢人。）
45. 表里的数和正文里引用它的那句话对得上吗？逐个数核，别只核第一行。
46. 计数类的说法（「十一组都是 7 遍」「另外八格没动」）是否真的数过？终点格算不算，先说清楚。

## 比喻（必查）

47. 全文搜「账」「钱」「买」「免费」「白给」「红利」「天花板」——记账 / 买卖那一套比喻，一处都不该留。
    每一处都问一遍：这里准确的说法是什么？（多半是「这一步的奖励」「打折后的未来值」「更新次数」。）
48. 全文搜「一台机器」「喂」「吃进」「吐出」——算子就写算子，作用就写作用。
49. 全文搜「炸了」「出事」「甩」「护栏」「埋线」「踩」——发散、失效、变慢，直说。
50. 全文搜「干净」「漂亮」「聪明」「厉害」「神秘」「划算」——含糊的评价词，把它换成具体的那一句。
51. 全文搜「当然」「确实」——和「显然」同一家。去掉之后句子不缺字的，就该去掉。
52. 判据只有一条：**把这个词遮住，读者能不能自己说出那里到底是什么量、好在哪？** 说不出来就是替换掉了解释。

## 位置与可核对（必查）

53. 两个概念第一次并排出现的那一节，有没有把差别讲透？还是把解释拖到了下一课？
54. `<footer>` 里点名的每个脚本，是不是真的在仓库里、真的能一次跑完？
55. 路线图：内部 slug（`stage0-lesson1` 这类）有没有印在页面上？已写完的课有没有做成链接？
56. 路线图：改过分节之后，全文搜「Stage」加数字，还有没有指向旧编号的引用？
57. 路线图：每张卡片的标题和它底下那串条目对得上吗？拆分小节最容易留下一张旧卡。
