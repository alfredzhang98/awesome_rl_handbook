# 语气、句式与修辞

例句全部摘自 `RL_Handbook_CartPole.html`，可以直接当模板改写。

## 一课的叙事骨架

```
① 上一课留下的东西    「前面三课的每一个数字，都是算出来的——因为 r 和 s' 你都知道。」
② 这一课拿掉/加上什么  「这一课把模型拿走，只留下一条条跑出来的轨迹。」
③ 一个能手算的小例子  五状态链 / 崖边链 / 8 集的 A-B 例子
④ 从例子里读出规律    表格连列 10 行，让读者自己看出 0.900
⑤ 才是形式化          算子、定理、收敛性、误差界
⑥ 在本课例子上落地    CartPole 上的图与数字
⑦ 边界与坑            什么时候这套东西不成立
⑧ N 句话收尾          编号列表，每条一句，能背下来
```

## 开场句式

- 「这一课不推公式。我们只做一件事：**把一个具体的数刷出来**。」
- 「前面三课的每一个数字，都是算出来的……这一课把模型拿走。」
- 「你已经把 DQN 拆完了，只是还没人告诉你。」
- 「你现在手上的整条流水线，最后一步都是这个：a* = argmax Q(s,a)。」——先摆出读者已有的东西，再指出它在哪断掉。

## 破误解优先

新概念不从定义讲起，从**读者大概率的错误理解**讲起：

- 「V_k 不是什么"迭代中间量"。它是一个**独立成立的、精确的答案**——只不过回答的是"只剩 3 步"这个问题。」
- 「前 4 遍的 0 是**正确答案**，不是"没算准"。」
- 「很多人从表格法直接跳到 DQN，于是永远不知道 replay buffer 和 target network 到底在修什么。」
- 「一个决定性的论据，说明 k 不可能是时刻。」

## 白话复述

每个公式后面接一句「翻译」，句式固定：

- 「这个式子读一遍就够了：误差不是"在原地缩小"，而是"从下游搬过来、顺便打了个 γ 折"。」
- 「"值迭代"翻译成大白话就是：把预算一路加上去，加到再加也没用。」
- 「这里没有任何近似、没有任何假设，就是把一个无穷和重新分组。」
- 「递归把无穷次加法换成了有限次、每次一步的迭代。**这就是 Bellman 方程真正买到的东西。**」

## 承认难点和意外

- 「然后是本课最让我意外的一个数字。」
- 「一个值得记住的对立。」
- 「但代价请看清楚。」
- 「这是真正的卡点，也是最值得想明白的一步。」
- 「务必盯住最后那个条件——这是最容易读错的地方。」
- 「但请注意这两条只是充分条件。」

## 结论的写法

结论要**可执行、可反驳**，不要「很重要」「非常关键」：

- ✅「如果起点离奖励有 50 步，你至少要刷 51 遍才第一次看见非零值。稀疏奖励难学，难就难在这里，跟算法聪不聪明无关。」
- ✅「贪心策略远在值函数收敛之前就已经最优了。」
- ✅「"要不要衰减"取决于目标有没有噪声，**不取决于算法叫什么名字**。」
- ❌「值迭代是一个非常重要的算法。」

## 加粗与强调

| 手段 | 用在哪 |
|---|---|
| `<strong>` | 可执行的结论、判断句。一段最多一处 |
| `<b>` | 数字、块首断言、表格里的关键值、图题里的结论词 |
| 「」 | 口语化的名字：「刷一遍」「上一稿」「盯住三件事」 |
| "" | 引述别人的说法或错误说法：「不是"没算准"」 |
| `<code>` | 函数名、文件名：`solve_discrete_are`、`arm_dp.py` |
| `<em>` | 极少用，用于自问自答里的那个问句 |

术语第一次出现**不加粗**，用公式或 `<code>` 呈现；加粗留给结论。

## 收尾节

固定叫「N 句话收尾」，编号列表，每条 `<b>一句断言。</b>` 打头，后面补一句解释：

```html
<ol>
<li><b>没模型不改变任何理论，只改变一件事：期望算不出来。</b>于是"精确期望 + 直接赋值"变成"一个样本 + 挪 α 那么多"。</li>
<li><b>DP 是「整张表一次一次刷」，TD 是「一条轨迹一条轨迹漂」。</b>……</li>
</ol>
```

## `<footer>` 两件事

```html
<footer>
下一课进 Stage 5：策略梯度。到目前为止你学的全是"学值，然后 argmax 出策略"——那条路在连续动作上直接断掉。<br>
本课所有数字都是跑出来的：消融的四格、打滑版 DP 的重算、以及 Double DQN 那个带符号偏差。
</footer>
```

1. **下一课去哪，以及为什么是这个顺序**（依赖关系，不是时间表）。
2. **数字与图的来源脚本 + 重跑耗时**（「整跑约 4 分钟」）。

## 中文排版

- 中英文/数字之间留一个空格：「跑 3721 格」「用 Fourier basis（阶数 3~5）」。
- 全角标点；破折号用 `——`；省略号用 `…`。
- 数字带精度并统一小数位；比值写成「106 倍」「11 倍」而不是「一个数量级」。
- 单位与口径讲清楚：「44 小时真机时间」「16 万步」「约 90 秒重跑」。

## 禁忌

- 不写没跑过的数。
- 不写「显然」「不难看出」；难就说难。
- 不在同一课里换符号而不公告。
- 不用没有信息量的图题。
- 不堆术语开场——术语要等到读者已经看见那个数字之后才出现。
