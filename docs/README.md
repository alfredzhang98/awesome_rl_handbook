# Awesome RL Handbook

讲义正文所在目录，GitHub Pages 从这里发布。每一课是一个独立 HTML，
自带侧边栏目录、章节索引与上一章/下一章导航。

从 [`index.html`](index.html) 开始阅读；目录见 [`SUMMARY.md`](SUMMARY.md)。

| 文件 | 内容 |
|---|---|
| `index.html` | 路线图 |
| `ch0.html` | 第 0 课 · 值函数与最优值函数 |
| `ch1.html` | 第 1 课 · MDP 与 Bellman 算子 |
| `ch2.html` | 第 2 课 · 动态规划 |
| `daily/index.html` | 每日一问 · 总目录 |
| `daily/001.html` | 每日一问 Day 1 · MC / TD / DP 的关系 |

`assets/book.css` = 设计系统 + 书本版式；`assets/book.js` 负责侧边栏与本章小目录。
数学公式的 SVG 字形定义按页面实际用到的部分分发到每一页，离线可直接双击打开。
