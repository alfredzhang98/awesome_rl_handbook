    把表换成函数
    以及所有保证是怎么坏掉的

    前五课的每一个收敛结论，都建立在同一个前提上： 是一张表，每格独立。这一课把表换成 ，然后看着 Baird 反例把参数指数级吹上天——同一个算法，只要去掉三条腿里的任意一条，就完全没事。
    这一课数学密度最高，但它是理解 DQN 那三个"魔法补丁"的唯一入口。

    § 1为什么必须换：两个理由，第二个更重要

    问题CartPole 上的具体数字
    ① 存不下 随维度指数爆炸2 维 61 格 = 3721；完整 4 维 = 1380 万；12 自由度机器人（24 维）无从谈起
    ② 不泛化每一格是陌生人 学到的东西，对隔壁 一点用没有
    第二条才是真正的理由。就算你存得下，表格法也需要把每一格都亲自撞一遍——那正是第四课那 800 万步的来源。

    可这里有个陷阱：目标里也有 。真梯度会多出一项 。实际用的更新故意把它扔掉：

    这叫「半梯度」（semi-gradient）：目标被当成常数，不参与求导。

    为什么要这么干？因为我们想要的不是"让两边尽量接近"，而是"把 朝 推"——那个目标代表的是更可信的信息（含一步真实奖励），不该被拖着一起动。真梯度（residual gradient）会让两边各让一步在中间会师。它优化的是 Bellman 误差 BE 而不是投影 Bellman 误差，实践中给出的值通常更差（Scherrer 2010）——但真正致命的是另一条：随机环境里它需要同一个 的两个独立后继样本（double sampling），否则最小化的是一个被方差污染了的目标，而且 BE 本身无法只从数据里辨识（S&B §11.6）。这才是它在实践中用不了的主因。

    代价：半梯度不是任何函数的梯度。于是"沿着梯度走一定不上升"这个护身符没了——这是本课所有麻烦的技术起点。

    在代码里它就是 PyTorch 的一行 .detach() 或 with torch.no_grad()。你以后每次写这一行，就是在做这个取舍。

    § 5致命三角：三条腿，抽掉任意一条就站不住

    我把三条腿逐一去掉，跑同一个反例：

    配置函数逼近自举off-policy结果（跑 20 万次后的加权 RMSE）
    Baird 原版✓✓✓发散（ 4190 步破 ）
    换成表格特征✗✓✓收敛（0.574，按 的速率老实往 0 走）
    换成 MC（不自举）✓✗✓收敛（）
    换成 on-policy✓✓✗收敛（）
    三条腿：函数逼近 + 自举 + 离策略。
    但"去掉任意一条就安全"要加限定，否则就成了口号。上面这张表成立的范围是：线性逼近 + 预测（给定策略估值）。出了这个范围有两个已知的反例——

    ① 非线性逼近下，即使 on-policy，TD 也可能发散（Tsitsiklis & Van Roy 1997 给了具体构造）；
    ② 控制问题里（目标带 ），on-policy 的 Sarsa + 线性逼近没有收敛证明，可能在若干策略之间反复震荡（Gordon 1996）。这和下面那句"用 时连 on-policy 都救不了"是同一件事。

    反过来也一样：三条腿齐备并不保证发散——你每天跑的 DQN 三条全占，多数时候不炸。致命三角是一条危险性提示，不是"当且仅当"的定理。

    为什么是这三条：两个范数对不上

    上函数逼近之后，你每一步实际在做的不是 ，而是

    两个算子各有各的"好性质"，但它们活在不同的度量里：

    sup 范数 加权 范数
    （带 max）✓ 压缩✗ 一般不压缩
    ✓ 压缩✓ 但只在 时
    （最小二乘投影）✗ 会放大✓ 非扩张（正交投影）
    看第二行第三列那个"但"字——整个致命三角就压在它上面。

    on-policy 时：数据分布 恰好是 的稳态分布。这时 在 下也是 压缩，而 在同一个范数下非扩张 → 是压缩，收敛，误差有界（§3 那张表）。

    off-policy 时：， 在 下不再压缩； 又只在 下听话。两个范数对不上，复合起来一半保证都不剩。

    用 （）时：连 on-policy 都救不了，因为 在任何加权 下都不保证压缩。

    所以严格讲，Q-learning + 神经网（也就是 DQN）从来就没有收敛保证。它能 work 是工程的胜利，不是定理的胜利。
    第三条腿为什么躲不掉。你可能想"那我一律 on-policy 不就行了"——问题是 off-policy 是你真正想要的东西：
    ① 想用 replay buffer（旧数据来自旧策略）→ off-policy
    ② 想用 学最优策略而不是当前策略 → off-policy
    ③ 想用示教数据 / 别的控制器采的数据 / 离线数据集 → off-policy

    DQN 三样都占。所以 Stage 4 那些补丁不是可选项。

    在同一个 Baird 反例上，TDC 不发散（ 稳在 8.7 附近）；把步长调到 跑 20 万次，加权 RMSE 降到 0.18 并继续往 0 走。注意它不是单调下降的——头十来次迭代反而从 11.4 冲到 19.4 才回头，这是两个时间尺度还没配合上的暂态。Emphatic TD 是另一条路——重新加权状态使 变回"像 on-policy"，也有收敛证明。

    但要说清楚：这一族在深度 RL 里几乎没人用。多一组权重、多一个学习率、方差更大，而在实践里 DQN 那套工程补丁便宜又够用。知道它们存在的价值是：它证明了"发散"是可以被根治的，而不是玄学。

    路二：工程上把它按住（这是实际在用的）

    补丁修哪条腿机制
    target network缓解自举（不是去掉）目标里用冻住的旧参数 。这就是把 DP 的"上一稿"搬回来（第四课 §3 那张两行表的第二行）——目标仍然是自举来的，只是在一个窗口内不再跟着自己晃
    replay buffer反而制造 off-policy它的好处是打散相关性、复用样本、把状态分布摊平；代价是旧数据来自旧策略，离策略程度被它加大了
    Double DQN 的正偏差第四课 §7 那个最大化偏差，换到神经网上更严重
    小学习率 / 梯度裁剪 / Huber发散的速度治标，但常常够用
    DQN 那三个"魔法补丁"，到这里全部有了出处：

    replay buffer ← 样本复用 + 打散相关性（顺便把离策略那条腿做粗了）
    target network ← 本课的自举腿（把 DP 的两行结构还回来）
    Double DQN ← 第四课 §7 的最大化偏差

    但别把它们当成"定理级的修复"。我在 Baird 上试过 target network：同步周期 100 步时 稳在 8.8，1000 步时 11.8——有效；但同步周期 10 步就飙到 ，1 步（等于没有）。它有效的条件是 相对 足够"陈旧"，而且它既没有去掉自举、也没有恢复收敛保证（近年有针对增强变体的证明，Zhang 等 2021）。

    这三样是三条腿各挨了一刀，不是三条腿被砍断。

    机理是本课前面两件事在同时发力：

    1. 的正偏差 × 泛化（主因）。一个瓦片同时盖住"还能活很久"和"马上要摔"的格子，它们共用同一个参数。摔的那侧被邻居抬高， 又专挑被抬高的那一侧——误差不会左右抵消，只朝上单向累积；再经自举一轮轮放大。表格法没有共享，所以它的偏差符号正好相反（−11.39，那是"还没学完"的欠估，会随时间继续降到 0）。

    因为决策只关心 和 谁大，不关心它们各自偏了多少——只要偏得方向一致，argmax 就不受影响。

    上面那个 +21.41 其实就是你以后一定会在 DQN 上遇到的那个现象的一个可测样本：DQN 训出来的 Q 值经常离谱地高（动辄高估几倍），游戏却打得很好。值和策略是两个不同的精度要求，而我们真正要的只有后者——这也正是 Double DQN 要修的那条腿（§6）。反过来说，如果你用 值本身做安全判据（比如"值 > 阈值才算安全"），这个 +21 会直接咬你：它给的是偏乐观的安全余量，这在 robotics 上是很实际的坑。

    § 8六句话收尾

    1. 换函数的理由不是"存不下"，是"不泛化"。泛化和干扰是一体两面：改一个参数会动很多状态，表格法"每格独立"这个所有证明的地基就没了。
    2. 半梯度是故意扔掉一半导数（目标不参与求导，代码里就是 .detach()）。它不是任何函数的梯度——所有麻烦的技术起点。
    3. on-policy + 线性：可证收敛，误差 最佳逼近。实测差距只有理论允许的一小部分。但 时这个放大系数会爆（0.999 时是 22.4 倍）。
    4. 致命三角 = 函数逼近 + 自举 + 离策略。Baird 反例里真值 0 且完全可表示，照样指数发散；去掉任意一条腿立刻收敛。
    5. 根源是两个范数对不上： 的压缩活在 sup 范数， 的非扩张活在加权 。只有 on-policy 的 恰好在同一个范数下也压缩——这是唯一那扇门。
    6. DQN 的三个补丁各修一条腿：target network 修自举（把 DP 的"上一稿"搬回来）、replay buffer 缓解分布问题、Double DQN 修 的正偏差（§7 那个 +21.41 就是它的一个可测样本）。严格说 DQN 至今没有收敛保证——它 work 是工程的胜利。
    下一课进 Stage 4：DQN 家族。到那时你会发现自己已经把它拆完了——剩下的只是"把线性换成卷积网，再把这三个补丁按顺序装上去"，以及 Rainbow 里那另外三个（优先回放 ≈ 第五课 §3 的优先扫描、多步回报 = 第五课 §2 的 n-step、分布型 RL（distributional）= 学整个回报分布而不只是均值）。
    本课所有数字都是跑出来的：Baird 的 4190 步破百万、误差界的七组特征、CartPole 的 1296 参数 / 16 万步、以及 §7 那个"把 拿掉，+21.41 就变成 −7.39"的对照实验。
