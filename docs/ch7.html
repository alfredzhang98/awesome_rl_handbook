    DQN 家族
    三个补丁，各修一处

    你已经把 DQN 拆完了，只是还没人告诉你。它就是 Q-learning + 神经网 + 三个补丁——而那三个补丁修的东西，你在第四、五课里全都见过。
    这一课把它们装起来，然后一个一个拆掉，看少了谁会怎么死。所有数字还是跑在第一课那个 3721 格的精确 CartPole 上，因为那里有 DP 算出来的真值可以对照。

    § 1DQN 的零件，你在哪一课学过

    先把完整的 DQN 摆出来。看一眼有几行是你不认识的：

    # 初始化
    Qθ ← 随机初始化的网络
    Qθ⁻ ← Qθ 的一份拷贝   # 补丁①：target network
    D ← 空的 replay buffer   # 补丁②：经验回放

    每一步：
      a ← ε-贪心(Qθ(s, ·))   # 行为策略：带探索
      执行 a，观察 r, s′, done
      D.存入 (s, a, r, s′, done)

      从 D 里随机抽一个 minibatch
      y ← r + γ(1−done)·maxa′ Qθ⁻(s′, a′)   # 用旧网络算目标
      L ← ( y.detach() − Qθ(s, a) )²   # 半梯度
      θ ← θ − α∇θL

      s ← s′（或 done 就重开一集）

      每 C 步：Qθ⁻ ← Qθ   # 换稿

    把三处高亮全部还原成"用当前网络、只用刚刚这一条转移"，剩下的就是第四课 §7 那个 Q-learning：

    零件你在哪儿学的一句话
    第四课 §7Q-learning 的目标，off-policy 但不需要 IS
    ε-贪心行为策略第四课 §6覆盖问题：没走过的格子学不到
    网络代替表第六课 §1不是"存不下"，是"不泛化"
    .detach()（半梯度）第六课 §2目标不参与求导。表格法其实是它的特例：特征取 one-hot 时 就是一个 one-hot 向量，更新只落到那一格
    replay 里全是旧策略的数据第五课 §4Q-learning 免疫，所以敢这么干
    的正偏差第四课 §7Double 要修的就是它
    DQN 真正新的东西只有两样：target network 和 replay buffer。
    剩下全是你已经有的零件。这一课的重点不是"它是什么"，是"少了它们会怎么死"。

    还有一层工程外壳，伪代码里没写但实验里都开着：优化器用 Adam（不是朴素 SGD）、损失用 Huber（不是平方，对离群目标更钝）、梯度按范数裁到 10。这三样本身就有抑制发散的作用——所以下面"不装补丁会炸"的结论，是在已经有这三层保护的前提下得到的，实际只会更糟。

    § 2先看不装补丁会怎样

    把补丁全部拆掉——就是"Q-learning 的更新式子，只不过 换成一个网络"。这也正是第六课 §2 那个半梯度更新，一步不差：

    实验设置：第一课那个 3721 格 CartPole（确定性、每步 +1、），网络是 2 → 64 → 64 → 2 的小 MLP，输入是归一化的 。因为环境是查表的，DP 的真值 、 全都精确已知，可以直接量误差。

    这个 MDP 上 在可行域里恒等于 ——这是任何状态在数学上可能达到的最大值（每步奖励最多 1）。越过 100 就说明有偏差；但越过多少很重要：正常收敛的 DQN 也会有几个百分点的格子擦到 100 以上（最大 105），那是逼近误差；下面凡是看到 冲到 以上的，都是真的坏了——那已经是天花板的十倍以上，任何逼近误差都解释不了。

    § 3补丁①：target network —— 把 DP 的「上一稿」搬回来

    而 TD 把下标扔了，读的是活表：

    表格法里这没事——改一格只动一格， 不会因为你改了 而动。但换成网络就不一样了： 一动， 跟着动，你正在追的目标被你自己推着跑。

    target network 就是把 DP 那个「冻结的上一稿」搬回 TD 里。
    每 步才同步一次；这 步之内，目标是钉死的。
    实测：这是三个补丁里唯一一个"拆了就死"的。

    去掉 target network（replay 照留），2 个种子全部发散： 的均值冲到 ，是理论上限 100 的五万六千倍；策略一致率掉到 0.5000，也就是和抛硬币一样。

    而完整 DQN 的 是 1.59。差了六个数量级，中间没有灰色地带。

    不过这一格我只跑了 2 个种子（"两个都去掉"那格跑了 8 个）。按 §5 自己的标准，2 个种子说服力有限——只是这里的差距实在太大（ 量级 vs 个位数），再加种子改变结论的可能性很低。

    § 4补丁②：replay buffer

    它干两件事：

    做什么为什么要
    打散相关性不按时间顺序学，随机抽连续几步的 高度相关，SGD 的"独立同分布"假设全废
    数据复用一条经验被抽中很多次真机上每一步都很贵（第五课 §3 那笔 44 小时的账）
    但注意一件容易被忽略的事：replay buffer 制造了 off-policy，而不是修好了它。
    buffer 里躺着的是几万步以前那个策略跑出来的数据，和你现在的 早就不是一回事了。DQN 敢这么干，唯一的理由是第五课 §4 那件事：Q-learning 的一步目标里没有"按策略采样再平均"的动作，所以不需要任何 IS 修正。

    换成 SARSA 就不行——它目标里那个 属于存进 buffer 时的那个旧策略。
    实测：在这个问题上，replay 拆了几乎没事。

    换成"最近 64 条连续转移"（batch size 保持 64），跑 8 个种子，一个都没发散。 从 1.59 变成 5.14（中位数）——变差了，但完全能用。

    诚实说清楚为什么这里 replay 显得没用，因为这跟 Atari 上的结论不一样：
      ① 这里的"环境"是一张查找表，采样是免费的——replay 最大的卖点"数据复用"在这里一文不值；
      ② 我们每 500 步就从随机状态重启一次，相关性本来就被打断了不少；
      ③ 状态只有 2 维、3721 格，覆盖很快就满了。

    真机上这三条全都反过来——所以别把这一格的结论外推成"replay 没用"。它在这里的作用小，是因为这个问题恰好不需要它。

    还得说清楚这个消融没测到什么：我用的是"最近 64 条"的滑动窗口，所以每一条转移仍然参与了 64 次连续的梯度更新——数据复用其实还在，被拆掉的只有"打散相关性"这一半。所以严格说，这一行测的是「随机抽样 vs 顺序取用」，不是「有 replay vs 没 replay」。真要测复用，得让每条转移只用一次。

    § 5四格消融表

    把两个补丁做成 2×2，再加一个"最朴素"的版本。指标是 15 万步时的 （可行域均值），并且我数了有多少个随机种子跑炸了（判据： 的均值超过 1000，也就是天花板的 10 倍以上）：

    三句话读完这张表：

    ① target network 是承重墙。拆了必炸，而且是六个数量级的炸。
    ② replay 在这个问题上是装修。拆了误差从 1.59 变 5.14，八个种子一个没炸。
    ③ 但看第四行那个 7/8——不是 8/8。有一个种子活下来了， 是 3.11，跟正常的 DQN 差不多。
    第三条正好把第六课那句话变成了可测的东西。第六课 §5 写着："三条腿齐备并不保证发散——你每天跑的 DQN 三条全占，多数时候不炸。致命三角是一条危险性提示，不是当且仅当的定理。"

    这里就是那句话的实测版：同一个配置、同一份代码，只换随机种子——7 个炸到千万量级，1 个稳稳停在 3.11。
    所以"我跑了一次没炸"从来不是证据。这也是为什么补丁值得装：你要的不是"通常没事"，是"别赌"。

    § 6补丁③：Double DQN —— 但先得让偏差长出来

    第四课讲过 的正偏差：——只要估计里有噪声，取最大就会系统性偏高，因为 专挑那些"这次运气好、被高估了的"。

    可是上面那个确定性 MDP 上，DQN 的高估几乎看不见（超过 100 的格子只有 3%）。这不是因为环境是确定的。

    放大的是估计误差，不管这个误差来自环境噪声、采样噪声，还是函数逼近本身。证据就在第六课 §7：同一个确定性 MDP，换成 tile coding 之后高估到 +21.41、92.7% 的格子越过 100——那里根本没有环境随机性，靠的纯粹是逼近误差。而这里的小 MLP 拟合得太好（），估计误差小，所以 没什么可放大的。

    所以要把这个现象逼出来，得给 一个不会随训练消失的噪声源。真机上现成就有一个：执行是会打滑的。

    所以这一节换一个环境：同一个 CartPole，但以 10% 的概率，你发出的动作被翻转（推左变成推右）。DP 重算一遍，两个副产品立刻出现：

    原版（确定性）打滑版（）
    在可行域上恒等于 100（一个常数）[33.91, 99.93]，均值 89.07，标准差 17.20
    两动作真有差别的格子4461930
    最好的线性分界能达到100%（完全线性可分）98.24%
    顺带把第六课 §7 留的一个尴尬补上了。那里我们发现 在可行域上恒等于 100 是个常数——瓦片表示它易如反掌，所以"逼近能力不够"根本不成立。
    打滑版里 终于是一个真正的形状了（标准差 17.2），值函数逼近这件事才有了实质内容。而且 的正偏差也有了土壤。

    Double DQN 的修法就一行——把"选哪个动作"和"用谁的值"拆开：

    DQN         — 同一张网既选又评

    Double DQN    — 在线网选，目标网评

    直觉：一个动作要被高估，得同时在两张网里都运气好。选它的那张网被自己的噪声骗了，评它的那张网不会跟着一起骗。

    三个种子的平均（20 万步）：
    带符号偏差 超过上限 100 的格子
    DQN+10.8986.9%10.89
    Double DQN+8.310.1%9.32
    两栏要一起读，单看哪一栏都会骗人：

    ① "超过 100 的比例" 86.9% → 0.1% 看着惊人，但它有放大效应。学到的值分布很窄：DQN 均值 99.96、标准差 5.9、最大只有 104.2；Double 均值 97.38、标准差 5.3、最大 100.3。一个 2.6 的整体平移，穿过 100 这条硬边界，就把比例从 87% 推到了 0.1%。真实的改善没有三个数量级那么夸张。

    ② 带符号偏差 +10.89 → +8.31，只降了 24%——这才是老实的幅度。Double 只消掉" 那一份"，剩下的来自半梯度、离策略、以及网络本身的逼近误差。

    那为什么还要看第一栏？因为它锁定了方向： 在可行域上最大 99.93，而 DQN 87% 的格子压在 100 的右边、Double 只有 0.1%——两个模型的整团分布落在了这条线的两侧。这不能证明幅度，但足以证明 DQN 是系统性偏高、而 Double 不是。
    别把"越过 100"当成"一定是 干的"。第六课 §7 那个对照实验里，完全没有 的纯策略评估也有 13.3% 的格子略高于 100——光滑的逼近器会把高值格子的值抹一点到邻居身上，个别格子越线很正常。能区分"逼近误差"和" 偏差"的不是"有没有越线"，是规模和方向：前者是零星的、正负都有；后者是整团的、单向的。

    而第四课那句话依然成立：Double 消掉的是正偏差，代价是引入负偏差。因为 ——它系统性地偏低。只是在"高估会被自举一轮轮放大、低估不会"这个不对称下，偏低远比偏高安全。

    Rainbow 的多步目标长这样：

    按第五课 §4，中间那 2 步是 buffer 里那个旧策略走的，理论上必须乘那个连乘 。Rainbow 不乘。

    这是个"理论上错、实践中人人都用"的著名 hack。你现在有工具去评判它，而不只是背它。

    Dueling：把 写进网络结构

    第二课 §4 那句" 是这个状态值多少， 是选这个动作比平均好多少"，在这里变成了网络结构：两个头，一个学 、一个学 ，最后相加。减去均值那一项是为了消掉 和 之间的平移歧义（否则 、 给出同一个 ，参数不可辨识）。

    好处：很多状态下动作根本不重要（CartPole 杆子快摔时，推哪边都一样）。dueling 让这些状态只需要学好一个 ，不用为每个动作各学一遍。回到本课的数据：那 1931 个可行格里只有 446 格两个动作真有差别（差值 ）——剩下 77% 的可行格，dueling 的 头一个数就够了。

    Distributional：把"均值"换成"整个分布"

    Bellman 方程可以写成分布层面的：。C51 把回报分布离散成 51 个原子来学。数学上很漂亮（分布 Bellman 算子在 Wasserstein 度量下是压缩的），实践上主要好处是训练信号更丰富——预测一整条分布比预测一个数给出的梯度信息多得多。

    同一个 CartPole， 换三种表示法。指标统一取 15 万步时：

    参数量策略一致率最终能到哪

    tile coding（第六课）12960.986549.79策略 99.8%，值停在 23.6

    这张表不能读成"神经网比瓦片强 31 倍"，因为三行改的不只是表示法。

    表格和 tile coding 那两行来自第四/六课的实验：朴素 SGD、每步一个样本、没有 replay、没有 target network。MLP 这一行来自本课：Adam + Huber + 梯度裁剪 + 50k 的 replay + batch 64 + target network。光"每个环境步做 64 个样本的更新"这一条，就是 64 倍的差距。

    所以诚实的读法是：这三行是"三套完整方案"的对比，不是"三种函数逼近器"的对比。要做后者，得把优化器和补丁全部对齐再跑一遍——我没做。
    但策略那一栏本身很有意思，而且方向和值那一栏一致：15 万步时表格还在 0.4978（抛硬币），tile coding 已经 0.9865，MLP 是 1.0000。

    MLP 的 1.0000 是"第一次探针（5000 步）就到了"——因为这个 2D 问题的最优切换面线性可分（我验过：一条直线就能达到 100% 一致）。所以对一个够光滑的逼近器，策略几乎是白送的；难的是值。但注意这不是普遍规律：tile coding 的第一次探针也只有 0.5000，表格更是 265 万步才到 90%。
    3-step 那一行我一开始算错了口径，这里说清楚。

    我的实现里 -step 是一次外循环走 步真实转移，所以 steps=150000 配 实际消耗了 约 45 万个环境步，不是 15 万。按"每个环境步"公平比，3-step 的 2.82（45 万步）明显差于 1-step 的 1.59（15 万步），不是我原来写的"差不多"。

    更有意思的是另一个数：3-step 里超过 100 的格子从 3% 涨到了 77%。我本来以为这是第五课 §4 那个"没做 IS 修正"的锅，做了对照才发现不是——把中间那两步换成贪心动作（这时行为策略和目标策略几乎一致），高估没有减少，反而是 86%。
    （这个对照也只是近似：动作是按采集当时的网络取贪心的，等它被回放时策略已经变了，所以 并不严格等于 1。）

    所以在这个问题上，多步带来的高估更可能是值传播更快、更容易冲过头叠加 偏差，而不是离策略造成的。这个错误解释我差点写进去。

    § 9八句话收尾

    1. DQN = Q-learning + 神经网 + 两个新零件（target network、replay buffer）+ 一个修正（Double）。别的全是你前六课已有的。
    2. target network 就是把 DP 的「冻结上一稿」搬回 TD。表格法不需要它，是因为改一格只动一格；换成网络，你追的目标会被你自己推着跑。拆掉它 2/2 种子发散到天花板的五万倍。
    3. replay buffer 干两件事：打散相关性、复用数据。它制造了 off-policy 而不是修好它——DQN 敢这么干，全靠 Q-learning 的一步目标不需要 IS。在这个查表环境上拆掉它 8/8 都没炸，但真机上那三条理由全反过来。
    4. "两个都去掉" 7/8 炸，1/8 没炸。这就是第六课那句"致命三角是危险性提示，不是当且仅当"的实测版。跑一次没炸不是证据。
    5. 放大的是「估计误差」，不是「环境噪声」。本课那个小 MLP 在确定性环境上拟合得太好（），没什么可放大的；而第六课同一个环境上的 tile coding 拟合得差，就高估到 +21.41。加 10% 打滑是为了给 一个不会随训练消失的噪声源。
    6. Double DQN 把"选"和"评"拆给两张网，超上限比例 86.9% → 0.1%。但带符号偏差只从 +10.89 降到 +8.31——它只消掉 那一份。
    7. Rainbow 六件里你已经会三件：multi-step（第五课 §2）、prioritized replay（第五课 §3）、Double（本课）。而它的 multi-step 不做 IS 修正，是个理论上错、实践中人人用的 hack。
    8. robotics 上最该记住的一条：策略对不代表值对。确定性版上 MLP 5000 步就 100% 一致，值却要十几万步才收敛；打滑版上 DQN 的策略一致率 85%，同时 87% 的格子的值压在理论上限 100 之外（虽然最多只超 4%）。别拿 值当安全余量——它偏乐观，而且偏的方向很稳定。
    下一课进 Stage 5：策略梯度。到目前为止你学的全是"学值，然后 argmax 出策略"——那条路在连续动作上直接断掉（ 对连续 没法枚举）。而这正是 robotics 的主场。策略梯度不学值再取 argmax，它直接对策略求导；你已经会的 GAE、重要性采样、信赖域，全都是为那一课准备的。
    本课所有数字都是跑出来的：消融的四格、打滑版 DP 的重算、以及 Double DQN 那个带符号偏差。
