    § 2板块规则

    1. 一问一个能手算的例子。例子小到能在纸上跑完，第一个数字不用跑代码就能自己验一遍。
    2. 先给数，再给公式。顺序永远是：一个具体的数 → 表格 → 图 → 才是定理和收敛性。
    3. 每个公式都拆开。关键式子像 这样把每一块标住，公式下面再挂一张符号表，逐条说清每个变量是什么、为什么在那个位置。
    4. 所有数字都是跑出来的。正文里出现的每一个数都来自一次真实运行，不确定的数不写。
    5. 写清楚边界。每一问都要回答「这套说法什么时候不成立」，而不只是「它是什么」。
    这个板块和正课是互补的：正课负责把一条路径走完，每日一问负责把路上那些「等一下，这两个为什么长得这么像」的疙瘩拆开。想从头读讲义，回路线图。
