    第一部分 · 基础（必须扎实，后面全部建立在这上面）

    STAGE 0

    形式化：MDP 与 Bellman 算子

    这一阶段不学任何"算法"，只建立语言。90% 的 RL 论文看不懂，是因为这一层没有推熟，而不是因为网络结构没见过。

    核心概念

    • MDP 六元组 、轨迹分布 、回报
    • 三个值函数：、、优势 ，以及它们的互推关系
    • Bellman 期望方程 与 Bellman 最优方程：注意后者是非线性的（含 ）
    • Bellman 算子 、 是 -收缩映射（sup 范数下）
    • Banach 不动点定理 ⟹ 唯一最优值函数存在、值迭代必收敛
    • 策略改进定理（Policy Improvement Theorem）——策略迭代收敛的全部依据
    • 占用测度 与 RL 的线性规划对偶形式 可选但很有用

    要自己写出来的：为什么 不破坏收缩性； 时收敛常数怎么退化。

    机械臂落点

    写出单个关节的连续动力学 I θ̈ = τ − b θ̇ + m g l sin θ（协作臂的肘关节量级：I = 0.075 kg·m²、mgl = 2.94 N·m、50 Hz、τ 限 ±2 N·m），把它离散化成一个真正的表格 MDP：状态 (θ, θ̇) 分箱，动作是力矩档位。这个离散 MDP 会一直用到 Stage 3。
    可视化：在 (θ, θ̇) 平面上画 V⋆ 的热力图——你会看到一条清晰的"还救得回来"的边界，这就是控制里的 viability kernel；它的右边界正好落在 arcsin(τ_max/mgl) = 42.8°，因为再远静止时连重力都顶不住。

    容易跳过但不该跳的：折扣因子 不是超参数而是问题定义的一部分。robotics 里 与 episode 长度、与 average-reward 形式的关系，值得单独想清楚。

    STAGE 1

    已知模型：动态规划 ↔ LQR

    你做 robotics，这一阶段是最容易建立直觉的桥：LQR 就是线性-二次 MDP 的解析解，RL 是它在非线性、未知模型下的推广。把这条线打通，后面所有算法都有落脚点。

    核心算法

    • 策略评估（迭代解 ）与直接解线性方程组的对比
    • 策略迭代 Policy Iteration：有限步收敛的证明
    • 值迭代 Value Iteration：几何收敛率
    • 广义策略迭代 GPI——理解它，后面 actor-critic 就是它的采样版本
    • 异步 DP / 优先扫描（Prioritized Sweeping）
    • 对照组：LQR、Riccati 方程、iLQR/DDP 你可能已会

    值迭代由收缩性直接得到几何收敛，再由贪心策略的次优性界得到"值误差 → 策略误差"的转换：

    第二个式子里的 （在有分布偏移时会变成 ）会在 TRPO、CQL、offline RL 的每一个界里再出现——记住这个"有效视界"因子。

    机械臂落点

    在离散化的关节上跑值迭代到收敛，得到"上帝视角"的 V⋆ 与 π⋆。这个解在后面每个阶段都作为 ground truth 用来量误差。
    然后在举直位形线性化，解折扣 Riccati 得到 LQR 增益 K = [5.68, 0.82]，把 xᵀPx 与 V⋆ 叠在同一张图上——小角度区两者压在一起（网格加密一倍，中位偏差从 44.6% 降到 4.7%），大角度区力矩饱和，线性律的假设失效。这一张图基本说明了 RL 该在哪一端接手。

    第二部分 · 无模型的核心机器

    STAGE 2

    无模型表格法：MC / TD / Q-learning

    丢掉 ，只剩采样。这一阶段的数学主线是随机逼近与偏差-方差权衡——它决定了后面每一个算法的设计动机。

    核心算法

    • Monte Carlo 预测：first-visit / every-visit，无偏但高方差
    • 重要性采样：ordinary vs weighted IS，方差可以无穷大的例子
    • TD(0)：自举带来偏差，换取方差和在线性
    • n-step TD 与 TD()：资格迹、前向视角 ↔ 后向视角等价性证明
    • SARSA（on-policy）vs Q-learning（off-policy）vs Expected SARSA
    • Double Q-learning（表格版，先在这里理解最大化偏差）
    • Dyna-Q：第一次接触"模型"的用法，为 Stage 7 埋线

    机械臂落点

    在同一个离散化关节上跑表格 Q-learning 和 SARSA。关键实验：把 ‖Q_k − Q⋆‖∞ 对着 Stage 1 的精确解画出来，你能直接看到随机逼近的收敛速度以及步长衰减的影响。
    第二个实验：把力矩上限压到重力矩之下（τ_max < mgl），关节必须"先让它掉一点再拉"——on-policy 与 off-policy 的差别在这里第一次变得可见：SARSA 学到的策略明显更保守，因为它把探索的代价算进了值里。

    STAGE 3

    函数逼近与致命三角

    很多人从表格法直接跳到 DQN，于是永远不知道 replay buffer 和 target network 到底在修什么。这一阶段是整条路径里数学密度最高、也最值得慢慢走的一段。

    核心内容

    • 线性值函数逼近与特征构造：tile coding、RBF、Fourier basis
    • 半梯度 TD：为什么它不是任何目标函数的真梯度
    • 投影 Bellman 方程 与算子 ；MSPBE vs MSBE 的区别
    • 致命三角：函数逼近 + 自举 + off-policy ⟹ 可能发散；Baird 反例必须自己跑一遍
    • LSTD / LSPI：最小二乘视角 可选
    • 梯度 TD 方法：GTD2、TDC、Emphatic TD 理论向，可选

    on-policy 线性 TD 的不动点误差界： ——逼近误差被放大了一个与 有关的因子，这是"能表示"和"能学到"之间的差距。

    机械臂落点

    把问题升到肩 + 肘两个关节（状态 4 维）。同样 121 格/维，表格要 2.14×10⁸ 个格点——先算这笔账，再动手。
    用 Fourier basis（阶数 3~5）+ SARSA(λ) 学这台两关节臂，不用任何神经网络：训练曲线远比 DQN 干净。这会让你对"深度"祛魅——两关节调节根本不需要深度网络。
    对照实验：把同一套线性特征换成 off-policy Q-learning 更新并去掉 target，观察参数发散。你会亲眼看到致命三角。

    这一阶段是分水岭。走完它，DQN 的每一个 trick 你都能预测出来，而不是背下来。

    第三部分 · 深度强化学习

    STAGE 4

    深度值方法：DQN 家族

    下一课

    对 robotics 来说这条线不是主线（动作是连续的），但它是理解 SAC / TD3 中 critic 部分的必经之路，而且分布型 RL（distributional RL）的数学很漂亮。

    核心算法

    • DQN：experience replay（打破相关性）+ target network（把移动靶变成半固定靶）
    • Double DQN：解耦选择与评估，直接对应 Stage 2 的最大化偏差
    • Dueling 架构： 与可辨识性问题
    • Prioritized Experience Replay：IS 权重修正引入的偏差
    • n-step DQN、Rainbow（消融实验本身就是很好的教材）
    • 分布型 RL（distributional）：C51、QR-DQN、IQN——分布 Bellman 算子在 Wasserstein 度量下的收缩性 数学向，推荐

    机械臂落点

    把两关节的力矩离散成档位，从零实现 DQN（约 150 行），然后做消融：去掉 target network、去掉 replay、两个都去掉。三条曲线并排，Stage 3 的理论就变成了实验事实。
    再画一张：DQN 的 max_a Q 估值 vs 真实回报——过估计的曲线会明显翘起来，Double DQN 把它压回去。在关节这种"很多状态下推哪边都差不多"的问题上，dueling 的收益也能直接看出来。

    讲义第 7 课 · DQN 家族
    STAGE 5

    策略梯度：REINFORCE → TRPO → PPO

    整条路径的数学高峰，也是 robotics 实际最常用的一支。策略梯度定理、自然梯度、信任域三者是层层递进的同一个故事。

    核心算法与定理

    • 策略梯度定理：，必须自己完整推一遍
    • REINFORCE 与 baseline：为什么减去 不改变期望却降低方差（最优 baseline 的推导）
    • Actor-Critic、A2C/A3C：用 critic 换偏差降方差
    • GAE：， 就是偏差-方差旋钮
    • 自然策略梯度：Fisher 信息矩阵、KL 的二阶近似、参数化不变性
    • TRPO：性能差分引理 + 单调改进界，KL 约束的由来
    • PPO：clipped surrogate 作为信任域的一阶廉价近似；以及它不严格等价于 TRPO 的地方

    性能差分引理（TRPO 的起点）： 单调改进界：

    机械臂落点

    同一台两关节臂，力矩不再离散，四个版本依次实现：REINFORCE → +baseline → A2C → PPO。
    核心可视化不是回报曲线，而是梯度估计的方差：每一步用同一批 rollout 估 N 次梯度，画方差的箱线图。你会看到方差逐级下降一到两个数量级——这才是这条线的真正主题。
    另外画 PPO 的 clip 触发比例与 KL 散度随训练的变化，直观看到"信任域"在做什么。

    讲义第 8 课 · 策略梯度
    STAGE 6

    连续控制：DDPG / TD3 / SAC

    robotics 的主战场。到这里力矩上限要压到重力矩之下，任务从「稳住」变成「举起来」，难度真正上来。

    核心算法

    • 确定性策略梯度定理 (DPG)：，与随机 PG 的极限关系
    • DDPG：DPG + DQN 的两个 trick；以及它出了名的不稳定
    • TD3：双 critic 取 min（压过估计）、延迟策略更新、目标策略平滑（正则化）——三个 trick 各修一个具体的数学病
    • 最大熵 RL 框架：软 Bellman 算子、软值函数 、能量基策略
    • SAC：重参数化技巧、自动温度调节（把 变成约束优化的对偶变量）
    • 动作空间处理：tanh 压缩后的对数概率修正项（Jacobian）——实现时最常见的坑

    最大熵目标：

    两个容易混淆的软值函数，务必分清： 两者只在 取到最优 Boltzmann 策略 时重合。log-sum-exp 就是"软化的 max"， 退化为标准 RL。

    机械臂落点

    把力矩上限压到 τ_max < mgl：关节再也不能一步举上去，必须先反向摆、借惯性把杆甩起来——这就是机械臂版的 swing-up，控制界的经典 benchmark，也是这台关节第一次变得真的不平凡。
    对比 TD3 与 SAC 的样本效率；把 SAC 学到的策略熵随训练画出来，看它如何从探索自动过渡到利用。
    再画一张相图：在 (θ, θ̇) 平面上叠加学到的策略轨迹，和能量整形控制器（energy shaping + LQR 切换）的轨迹对比——RL 会自己发现"泵能量"的多次摆荡策略。

    第四部分 · robotics 的关键分支

    STAGE 7

    基于模型的 RL：PILCO / PETS / Dreamer

    对 robotics 这是最重要的一章——真机上样本极其昂贵，model-free 的样本量根本不现实。带未知负载的关节 swing-up 正是这条线的标志性 benchmark。

    核心方法

    • Dyna 框架与 model-based value expansion (MVE)、STEVE
    • PILCO：高斯过程动力学模型 + 矩匹配做解析的长程不确定性传播 + 解析策略梯度。用极少的交互就解决 CartPole swing-up，这篇必读
    • PETS：概率集成模型 + 轨迹采样；区分 aleatoric 与 epistemic 不确定性
    • 采样式规划器：CEM、MPPI（与路径积分控制的联系）、随机打靶
    • MBPO：短程 rollout 的分支策略与它的单调改进界
    • 世界模型：Dreamer 系列（latent 动力学 + 在想象中学策略）、TD-MPC2
    • 模型误差与复合误差：为什么长 rollout 会崩，以及它和 Stage 8 的 covariate shift 是同一个病

    机械臂落点

    三件事：
    (1) 学一个动力学模型 f̂(x, τ)（末端还挂着一个质量未知的负载），画多步预测误差随 horizon 的增长曲线——复合误差一目了然；
    (2) 用学到的模型 + CEM/MPPI 做 MPC 完成 swing-up，不训练任何策略网络；
    (3) 复现 PILCO 量级的样本效率（十几次 trial、几十秒交互），和 Stage 6 的 SAC 放在同一张"交互步数 vs 成功率"图上。这张图会重塑你对 RL 在真机上可行性的判断。

    STAGE 8

    模仿学习与逆强化学习

    真实机器人里"奖励函数怎么写"往往比"怎么优化"更难。这一阶段回答：能不能不写奖励。

    核心方法

    • 行为克隆与它的失败模式：covariate shift，误差随时间 的复合界
    • DAgger：把 IL 转成 no-regret 在线学习，误差降到
    • 最大熵 IRL：配分函数、特征期望匹配
    • GAIL：占用测度匹配 = JS 散度最小化，与 GAN 的严格对应
    • AIRL：可迁移的奖励恢复
    • 现代机器人策略：Diffusion Policy、Flow Matching Policy、ACT——多模态动作分布 方向前沿

    机械臂落点

    用 Stage 1 的 LQR 或 Stage 6 的 SAC 当专家，采一批演示做 BC。然后故意只给少量演示，画出误差如何随时间步复合放大直到关节掉出可行域——这是 covariate shift 最干净的可视化。接着加 DAgger，看曲线被压平。
    再用 GAIL 从同一批演示学，比较它在专家没访问过的状态区域的表现。

    STAGE 9

    离线强化学习

    真机数据一旦采集就很贵，能不能只从固定数据集里学？这一支近几年在机器人领域权重很高。

    核心方法

    • 分布偏移与外推误差：为什么直接跑 off-policy 算法会灾难性失败（OOD 动作被 挑出来）
    • 策略约束类：BCQ、BEAR、TD3+BC（后者简单到只加一项 BC 正则，效果却很好）
    • 值正则类：CQL——保守 Q 的下界证明
    • 免查询类：IQL（expectile 回归，完全不评估 OOD 动作）
    • 序列建模视角：Decision Transformer、Trajectory Transformer
    • 离线到在线微调（offline-to-online）——真机部署最实用的一环

    机械臂落点

    真机上关节数据采一次就贵。用一个中等水平策略采一份固定数据集，分别跑：普通 TD3（会崩）、TD3+BC、CQL、IQL。
    画出 Q 值随训练的爆炸曲线——普通 TD3 的 Q 会涨到几百上千而真实回报却在掉，这是离线 RL 最经典的病征图。

    第五部分 · 进阶专题（按需取用）

    STAGE 10

    探索理论与 regret

    如果你关注数学层面，这是整条路径里理论最硬的一块，也是唯一有干净理论保证的部分。

    核心内容

    • 多臂老虎机：-greedy、UCB、Thompson 采样、Lai–Robbins 下界
    • 表格 MDP 的 regret：UCRL2、UCBVI，以及极小极大率 （时齐转移，Azar 2017）/ （时变转移）——注意 的幂次取决于设定约定，读论文时先看清楚，以及配套的信息论下界
    • PAC-MDP 框架、、R-MAX
    • 深度 RL 中的探索：count-based / pseudo-count、RND、bootstrapped DQN、内在动机
    • 线性/低秩 MDP 与 LSVI-UCB 理论向

    机械臂落点

    把任务改成稀疏奖励版本：只有末端进入目标 5 mm 容差球才给 +1，ε-greedy 基本学不动；加 RND 内在奖励后能学起来。画两组的状态访问密度热力图对比覆盖范围。
    这也解释了第 1 课那个数字：消息一遍只走一格，起点离奖励 50 步就至少要刷 50 遍才知道有这回事。

    STAGE 11

    Sim-to-Real 与 Meta-RL

    你最终要上真机，这一章是仿真和现实之间的桥。

    核心内容

    • 域随机化（DR）与自动课程式 DR (ADR)
    • 系统辨识 vs 随机化：把 sim-to-real 看作鲁棒控制 / 部分可观问题
    • 鲁棒 RL：Robust MDP、极小极大形式、与 控制的联系
    • POMDP 与循环策略：belief state、隐式在线系统辨识
    • Meta-RL：RL²、MAML、PEARL——快速适应新动力学
    • 分层 RL：options 框架、semi-MDP、Bellman 方程的扩展 可选

    机械臂落点

    把连杆质量、关节摩擦、负载、执行器延迟当作随机化参数训练一个策略，再在训练分布外的参数上测试。对比三者：固定参数训练、域随机化训练、带 LSTM 的循环策略（能在线隐式辨识负载质量）。第三个会明显更鲁棒——这就是 sim-to-real 里 memory 的价值。

    STAGE 12

    延伸：LLM / VLA 中的 RL

    不是必修，但机器人正在往 VLA（视觉-语言-动作）模型走，这些方法会和你的方向汇合。走完 Stage 5 之后再来看，会发现它们只是 PG 的特例。

    核心内容

    • RLHF 流程：偏好数据 → Bradley–Terry 奖励模型 → PPO with KL penalty
    • DPO：把 RLHF 的约束优化解析求解，消掉奖励模型的推导（非常漂亮，值得亲手推）
    • GRPO：去掉 critic，用组内相对优势——本质是带 baseline 的 REINFORCE
    • RLVR：可验证奖励下的推理训练
    • VLA 上的应用：、OpenVLA 及其后训练 与你的方向直接相关
